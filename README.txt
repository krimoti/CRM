סדר יום חכם — חבילת התקנה (PWA אמיתי, עובד אופליין, מותקן כאפליקציה)
=====================================================================

למה צריך את זה בכלל?
הקישור שקיבלת בצ'אט (claude.ai/artifact/...) מריץ את הכלי בתוך דף מוגן של Claude,
ושם אי אפשר לרשום "Service Worker" אמיתי או קובץ manifest נפרד — ולכן אי אפשר
להתקין אותו שם כאפליקציה אמיתית עם עדכוני גרסה. כדי לקבל את זה בפועל (באייפון
וגם באנדרואיד) צריך לארח את 4 הקבצים האלה (index.html, manifest.json, sw.js,
icon-192.png, icon-512.png) על כתובת משלך עם HTTPS. זה לוקח כ-2 דקות:

אפשרות מהירה (חינם, בלי לדעת לתכנת):
  1. היכנסו ל-https://app.netlify.com/drop
  2. גררו את כל התיקייה הזו (עם כל הקבצים) לתוך הדפדפן
  3. תקבלו כתובת HTTPS חיה תוך שניות
  4. פתחו את הכתובת בספארי (אייפון) או כרום (אנדרואיד) ←
     אייפון: כפתור שיתוף ← "הוסף למסך הבית"
     אנדרואיד: תפריט ⋮ ← "התקן אפליקציה" / "הוסף למסך הבית"
  מרגע זה האפליקציה תעבוד לגמרי אופליין, עם אייקון משלה, בלי שורת כתובת.

אפשרות קבועה: GitHub Pages / Vercel / כל שרת סטטי אחר — אותו עיקרון בדיוק.

איך עובד הניהול-גרסאות בפועל?
כל קובץ אופליין נשמר במכשיר דרך sw.js. כשתרצו לשדרג גרסה:
  1. עדכנו את הקובץ index.html (או בקשו ממני גרסה מעודכנת)
  2. שנו את המחרוזת CACHE_NAME בקובץ sw.js (למשל ל-'agent-day-v2.1.0')
  3. העלו מחדש לאותה כתובת
בפעם הבאה שמשתמש פותח את האפליקציה (גם אם היה אופליין), ה-Service Worker מזהה
גרסה חדשה, מוריד אותה ברקע, ומציג הודעה "גרסה חדשה הורדה — רענן את הדף כדי לעדכן".

עבודה בלי אינטרנט בכלל, בלי שרת, בלי PWA:
אפשר גם פשוט לפתוח את index.html ישירות (לחיצה כפולה במחשב, פתיחה מתוך אפליקציית
הקבצים באייפון/אנדרואיד). ספריית האקסל מוטמעת בתוך הקובץ עצמו — לא נדרש אינטרנט
בשום שלב, גם לא לייצוא/ייבוא ל-Excel. ההבדל היחיד מול PWA מלא: בלי התקנה על
מסך הבית ובלי מנגנון עדכון גרסאות אוטומטי — פשוט מחליפים קובץ כשרוצים גרסה חדשה.

שינוי מספר הגרסה בתוך האפליקציה עצמה:
בתוך index.html חפשו את "const APP_VERSION" ואת מערך "CHANGELOG" בתחילת הקוד,
ועדכנו אותם בכל שדרוג — כך משתמשים חוזרים יראו אוטומטית מסך "מה חדש".
